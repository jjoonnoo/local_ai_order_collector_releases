# Ddaeng LiveOrder 설치 파일

라이브 채팅 수신·발송·AI 주문 수집 프로그램의 공식 Windows 배포 저장소입니다.
소스는 별도 비공개 저장소에서 관리하며 이 저장소에는 설치 파일과 업데이트 패키지만 게시합니다.

## 다운로드

[최신 설치 파일 받기](https://github.com/jjoonnoo/local_ai_order_collector_releases/releases/latest/download/Ddaeng.LiveOrder-win-Setup.exe)

[버전별 배포 내역](https://github.com/jjoonnoo/local_ai_order_collector_releases/releases)

## 처음 설치

1. 땡피싱·잘파는걸 프로그램을 모두 정상 종료합니다.
2. Setup.exe를 실행한 뒤 설치된 Ddaeng LiveOrder 바로가기를 사용합니다.
3. 기존 설정·YouTube 로그인·로그는 AppData에 그대로 보존됩니다.
4. 새 PC의 인증키·설정은 담당자에게 별도로 전달받습니다. 이 저장소에 올리지 마세요.

Windows 10/11 64비트가 필요합니다. AI 모드는 기존처럼 Ollama와 모델을 준비합니다.

## 업데이트

담당자가 새 릴리스를 공개하면 다음 실행 때 확인하고 업데이트합니다.
다른 방송 창이 열려 있으면 업데이트를 미룹니다. 설정과 로그는 유지됩니다.
공개 릴리스는 담당자가 검증 후 수동으로 게시합니다. 일반 코드 커밋만으로는 업데이트되지 않습니다.
